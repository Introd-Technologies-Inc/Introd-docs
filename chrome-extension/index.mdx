The Introd extension has two separate LinkedIn data behaviors:

- connect an Introd account
- detect the LinkedIn session in the current Chrome profile
- capture visible identity and relationship fields while you browse permitted LinkedIn pages when the default capture settings are on
- start, pause, resume, and monitor a full-network connection import
- automatically resume an incomplete full-network import in an inactive LinkedIn connections tab
- show available warm-path context beside supported LinkedIn identities
- manage extension settings and clear browser-local data

> Last verified against extension version 1.8.4 source on August 11, 2026.

## Prerequisites

- A desktop version of Chrome
- An Introd account
- A LinkedIn account signed in in the same Chrome profile
- An Introd-provided testing build

## What the extension does not establish

- It does not guarantee complete coverage of your LinkedIn connections.
- It does not create a warm path when the Introd graph has no supporting evidence.
- It does not send an introduction request, email, or LinkedIn message.
- It does not ask you to enter your LinkedIn password into the extension.
- It does not have permission to read arbitrary websites.

## Controls are not interchangeable

- **Pause Sync** stops the active full-network import and its automatic background resume. It does not stop contextual identity capture on other LinkedIn pages.
- Turning off **Enable extension** or **Auto-capture profile context** makes the current background capture handler skip new profile-view signals and enrichment. It does not stop current-page diagnostics, unload the LinkedIn content script, revoke host access, or stop full-network recovery.
- Disabling Introd from `chrome://extensions` is the reliable way to stop its code from running on LinkedIn pages. Clearing local data does not delete records already stored by Introd.

Read [LinkedIn Integration](/chrome-extension/linkedin-integration) and [Permissions](/chrome-extension/permissions) before installing the testing build.

## Basic workflow

1. [Install the provided build](/chrome-extension/installation).
2. Open the extension and choose **Continue with LinkedIn**.
3. Finish sign-in and reopen the popup.
4. Keep LinkedIn signed in in the same Chrome profile.
5. Choose **Start Sync**.
6. Expect an incomplete run to continue or resume in an inactive LinkedIn connections tab until it is paused or completed.
7. Verify the imported count and current status.
8. Open a supported LinkedIn page to inspect available context.
