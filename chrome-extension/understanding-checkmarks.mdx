> Last reviewed against extension version 3.1.24 on October 30, 2026.

## The network status strip

The popup shows one status line for your network, with a check icon when things are in a good state.

| Status | What it means |
| --- | --- |
| LinkedIn network up to date | Introd reports your LinkedIn sync is current |
| Network synced | Introd holds a complete, verified snapshot of your first-degree connections |
| Network ready from N sources | Introd has relationship evidence from connected sources but no verified LinkedIn snapshot |
| Your LinkedIn network is syncing… | A sync is in progress |
| LinkedIn sync partially complete | Some connections are saved and more remain |
| LinkedIn sync needs attention | The last run failed and Introd will retry |
| Network source needed | Connect a source to get started |

Introd decides these states, not the popup. The check icon shows a state; it does not guarantee that every connection was imported.

## Connected sources

In the popup settings, each source (LinkedIn, Gmail, Google Calendar, Google Contacts, Outlook, Outlook Calendar) shows one of **Synced**, **Connected**, **Syncing**, **Needs attention**, **Unavailable**, or **Not connected**, with the last-sync time. **Connected** can mean a source is linked but not yet contributing evidence.

## The on-page i. button

The **i.** button on LinkedIn is not a sync indicator, a verification badge, or a success mark. It opens a lookup of Introd paths for that profile. It is not LinkedIn verification or an endorsement.

## What a status does not confirm

- every LinkedIn connection was imported
- every imported contact has complete profile data
- a particular target has a verified warm path
- a connector has agreed to make an introduction
- an introduction message was sent or delivered

## Verify before acting

1. Confirm the last-sync time.
2. Open [People](https://app.getintrod.ai/search/people) and inspect the actual target.
3. Review path evidence and connector identity.
4. Start a connector review only when the evidence supports it.

For status recovery, see [Troubleshooting](/chrome-extension/troubleshooting).
