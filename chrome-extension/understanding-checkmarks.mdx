> Last verified against current Extension Setup source on August 11, 2026.

## Extension Setup checklist

| Checklist item | When it is marked complete |
| --- | --- |
| Extension installed | The current Introd extension is active |
| Introd account connected | The extension detects an authenticated Introd account |
| Logged into LinkedIn | The extension detects a LinkedIn session in this Chrome profile |
| Profile detected | A LinkedIn profile identity is available from the current session |
| Connection import available | The extension found a visible connection total or imported records |
| Connections imported | At least one connection record has been imported |
| Graph updated | The sync reached the extension's completed graph-ready condition |
| Last sync completed | The extension has a recorded last-sync time |

## Progress is not the same as completion

During a run, the checklist can show progress while the sync state is Syncing, Paused, Retrying, or Partial. Imported records can exist before **Graph updated** is complete. An incomplete run can also make progress through automatic background resume without the popup remaining open.

## What a completion checkmark confirms

- the associated setup condition was observed by the current extension
- the condition applies to this Chrome profile and Introd account
- the extension has a recorded state for that item

## What it does not confirm

- every LinkedIn connection was imported
- every imported contact has complete profile data
- a particular target has a verified warm path
- a connector has agreed to make an introduction
- an introduction message was sent or delivered

## Verify before acting

1. Compare imported connections with the visible total when the popup provides both.
2. Confirm the last-sync time.
3. Open [People Search](https://app.getintrod.ai/search/people) and inspect the actual target.
4. Review path evidence and connector identity.
5. Save a draft rather than treating a checkmark as permission to contact someone.

For status recovery, see [Troubleshooting](/chrome-extension/troubleshooting).
