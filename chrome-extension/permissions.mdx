> Last reviewed against extension version 3.1.24 on October 30, 2026. This list matches the manifest in the published package.

## Browser permissions

| Permission | Current use |
| --- | --- |
| storage | Stores extension settings, your sync approval, sync status, and browser-local caches |
| alarms | Schedules the periodic check-in that asks Introd whether LinkedIn sync work is waiting |
| scripting | Runs the connection collector in a LinkedIn tab during a sync you approved |

## Website access

| Website | Current use |
| --- | --- |
| `https://www.linkedin.com/*` and `https://linkedin.com/*` | Shows the **i.** button on profiles, people-search results, and company People pages, and reads your first-degree connections during an approved sync |
| `https://getintrod.ai/*`, `https://www.getintrod.ai/*`, `https://app.getintrod.ai/*` | Links the extension to your Introd account and relays status to the Introd dashboard |
| `https://api.getintrod.ai/*` | Sends sync data and path lookups to Introd |

The extension adds scripts to these pages:

| Where | Script |
| --- | --- |
| LinkedIn profiles (`/in/…`), people search results, and company People pages | The **i.** button and path popover |
| Introd sign-in callback pages | Completes account linking |
| Introd website and app pages | Relays link and status messages with the dashboard |

The Introd website and app pages can also connect to the extension for these link and status messages.

## Permissions not requested

The extension does not request:

- the **tabs** permission
- access to every website
- clipboard access
- download management
- browsing-history access
- microphone, camera, or location access

## What a permission does not mean

Access to LinkedIn pages lets the extension run on those pages. The **i.** button reads only the profile's address and public identifier. During an approved sync, the collector reads your first-degree connections. The extension does not capture profile data as you browse, and it does not read messages or your feed.

## Review before approving

1. Confirm the extension name is **Introd for LinkedIn** and the publisher is Introd.
2. Compare Chrome's permission prompt with this page.
3. Stop and contact [help@getintrod.ai](mailto:help@getintrod.ai) if the extension asks for access outside these permissions or websites.

See [Integration Data Usage](/privacy-security/integration-data-usage) for the fields used after you approve a sync.
