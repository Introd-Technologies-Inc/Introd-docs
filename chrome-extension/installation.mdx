<Warning>
  There is no public self-service installation link in these docs. Continue only if Introd supplied the build and its installation instructions directly to you.
</Warning>

Before installing, read [LinkedIn Integration](/chrome-extension/linkedin-integration). The current build performs default-on contextual capture while you browse permitted LinkedIn pages, separately from the full-network import you start from the popup.

## Prerequisites

- Desktop Chrome
- The Introd-provided extension folder or archive
- The version or checksum supplied with that build
- Permission to use the testing build

Do not install an Introd extension obtained from a third-party download, forwarded archive, advertisement, or search result.

## Install the build

1. If Introd supplied an archive, extract it to a folder that you will not move during testing.
2. Confirm that the extracted folder contains manifest.json.
3. Open chrome://extensions.
4. Enable **Developer mode**.
5. Choose **Load unpacked**.
6. Select the folder that contains manifest.json.
7. Pin **Introd for LinkedIn** from Chrome's extension menu.

## Verify the installation

1. Open the Introd extension popup.
2. Open Settings using the gear icon.
3. Confirm that the footer identifies the extension as Introd and shows the expected version.
4. Return to the popup.

**Expected result:** the popup opens Extension Setup or the signed-in Introd home view. It does not replace the current browser tab.

## First connection

1. Open LinkedIn in the same Chrome profile and sign in.
2. Open the extension.
3. Choose **Continue with LinkedIn**.
4. Complete the opened sign-in flow.
5. Reopen the popup and choose **I finished signing in** if that control is visible.

**Expected result:** Extension Setup marks **Introd account connected** and **Logged into LinkedIn** when both sessions are available.

## Installation failures

| What you see | Recovery |
| --- | --- |
| Manifest file is missing or unreadable | Select the extracted folder that directly contains manifest.json |
| The extension appears with an unexpected name or version | Remove it and contact Introd before signing in |
| The extension disappears after moving the folder | Return the folder to its original path or reload the supplied build |
| Introd is not detected in Network Setup | Reload the extension from chrome://extensions and refresh Introd |
| The popup reports Connection error | Choose **Retry**; if it continues, reload the extension |

## Updates

Testing builds do not update through a public distribution channel. Use only the replacement build and version instructions supplied by Introd.

Continue with [LinkedIn Integration](/chrome-extension/linkedin-integration).
