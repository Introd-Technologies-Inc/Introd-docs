> Last reviewed against extension version 3.1.24 on October 30, 2026.

Before installing, read [Sync and consent](/chrome-extension/linkedin-integration). The extension does nothing on your LinkedIn network until you approve its consent prompt.

## Prerequisites

- Desktop Chrome
- An approved Introd account
- A LinkedIn account signed in in the same Chrome profile

## Install

1. Open **Introd for LinkedIn** in the [Chrome Web Store](https://chromewebstore.google.com/detail/eoancpljacjbffdfjlbchdaeoainbkkf).
2. Choose **Add to Chrome** and confirm the permissions Chrome shows. They should match [Permissions](/chrome-extension/permissions).
3. Pin **Introd for LinkedIn** from Chrome's extension menu.

You can also start from the install action in [Network Setup](https://app.getintrod.ai/setup-network). After a first install, the extension opens Network Setup for you.

Install only from the Chrome Web Store listing or from Introd's own pages. Do not install a copy from an advertisement, search result, or forwarded archive. Chrome installs from the Web Store; Introd has not published a separate Microsoft Edge listing.

## Link the extension to your account

1. Open the extension popup.
2. Choose **Connect from Introd dashboard**. A Network Setup tab opens.
3. Finish sign-in there if asked. The popup shows **Finish sign in** while it waits.
4. Return to the popup and choose **I finished signing in** if it appears.

**Expected result:** the popup shows your network and a connected indicator. The extension is linked to your exact Introd user and workspace. There is no LinkedIn password step.

## Verify the installation

1. Open the popup, then its **Extension Settings**.
2. Check the footer for the extension version and update status.
3. Choose **Check for updates** if you want to look for a newer version.

## Installation failures

| What you see | Recovery |
| --- | --- |
| The popup reports "GetIntrod is unavailable" | Choose **Retry**. If it continues, reload the extension in `chrome://extensions` |
| The popup says "Link this extension from your signed-in Introd dashboard" | Choose **Connect from Introd dashboard** |
| Network Setup does not detect the extension | Check that it is enabled for this Chrome profile, then reload Network Setup |
| The extension has an unexpected name or publisher | Remove it and contact help@getintrod.ai before signing in |

## Updates

Chrome updates Web Store extensions automatically. The extension settings show the current version and whether an update is available.

Continue with [Sync and consent](/chrome-extension/linkedin-integration).
