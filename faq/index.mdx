## How do I create an Introd account?

Open [Create account](https://app.getintrod.ai/sign-up). Email and password, Google, and LinkedIn are supported on the current sign-up page. Microsoft is not available there; connect Microsoft 365 from [Integrations](https://app.getintrod.ai/settings/integrations) after signing in.

## Where can I install the Chrome extension?

These docs do not provide a public store-install link. Install only an Introd-provided testing build and follow [Install a Testing Build](/chrome-extension/installation). Do not install archives or extensions found in advertisements, search results, or third-party downloads.

## What does the extension do?

The current extension is limited to:

- Introd authentication and extension settings
- LinkedIn session, connection sync, progress, pause, resume, and retry status
- default-on capture of visible identity and relationship fields across permitted LinkedIn pages while you browse
- automatic background resume of an incomplete full-network import in an inactive connections tab
- available warm-path context beside supported LinkedIn identities

It does not send LinkedIn connection requests, messages, or introductions.

Current identity selectors include messaging surfaces, and relationship parsing can inspect surrounding rendered text. See [LinkedIn Integration](/chrome-extension/linkedin-integration) for the data boundary and control matrix.

In testing build 1.8.4, **Nothing is sent automatically** means no outreach is sent automatically. Profile signals, diagnostics, enrichment requests, and connection-import batches can still be transferred automatically.

## Does Pause Sync stop all LinkedIn capture?

No. **Pause Sync** stops the full-network import and its automatic background resume. It does not stop contextual identity capture or current-page diagnostics during ordinary LinkedIn browsing. The extension settings do not stop every behavior either. Disable Introd in `chrome://extensions` if you need its code to stop running on LinkedIn pages.

## Why does LinkedIn say login required?

The extension uses the LinkedIn session in the same Chrome profile. Sign in to LinkedIn, wait for the page to load, reopen the popup, and choose **Try Again** or **Resume Sync** when offered.

## Why is my LinkedIn sync partial?

LinkedIn visibility, page rendering, session state, and rate limits can leave some connections unprocessed. Open the popup to read its status. Automatic background resume can retry an incomplete run; choose **Pause Sync** if you do not want it to continue. Compare the completed imported count in [Network Setup](https://app.getintrod.ai/setup-network).

## Why do I not see a warm path?

A target needs enough imported relationship context and an available connector for Introd to display a path.

1. Confirm that Network Setup shows imported connections.
2. Confirm Google or Microsoft sync status if you connected either source.
3. Search for the target again in [People Search](https://app.getintrod.ai/search/people).
4. If **View Paths** still reports no verified path, choose another target or add more authorized relationship data.

Shared company or community context is not proof that a warm introduction exists.

## How are TrustRank and connector confidence calculated?

The current UI displays TrustRank, confidence, and relationship-strength signals from available graph evidence. The public product source does not define a stable customer-facing formula. Treat the values as relative ranking signals, not probabilities or guarantees.

## What do Google and Microsoft import?

Google Workspace uses Gmail header metadata, Calendar event metadata, and Contacts data. Microsoft 365 uses basic Outlook mail metadata and Calendar metadata. The current syncs do not import email bodies, meeting contents, or private notes.

See [Integration Data Usage](/privacy-security/integration-data-usage) and [OAuth Permissions](/privacy-security/oauth-permissions).

## Does Save draft send the introduction?

No. **Save draft** stores the introduction record in Introd. It does not email the connector, send a LinkedIn message, schedule delivery, or contact the target. See [First Warm Introduction Draft](/getting-started/first-warm-introduction).

## How do I disconnect Google or Microsoft?

Open [Integrations](https://app.getintrod.ai/settings/integrations), open the provider card, and choose **Disconnect**. Introd clears its stored connection tokens and stops future sync. Previously imported Introd records remain, and provider-side consent is separate.

## Does clearing extension data delete my Introd data?

No. **Clear local extension data** removes browser-local auth state, settings, caches, queued signals, and diagnostics for that Chrome installation. It does not delete server-side Introd records, disconnect Google or Microsoft, or delete the account. Reinitialization restores the build's default-on capture settings.

## How do I request deletion?

Use the account deletion control in [Settings](https://app.getintrod.ai/settings) to start the current in-product flow. For complete scope, confirmation, or another privacy-rights request, email [privacy@getintrod.ai](mailto:privacy@getintrod.ai). See [Deletion and Privacy Requests](/privacy-security/gdpr-and-deletion).
