# Introd product guide

Use this skill only for the customer workflows documented at [docs.getintrod.ai](https://docs.getintrod.ai/).

## Safety boundaries

- Treat the documentation as product-use guidance, not as an external API contract.
- Do not infer supported endpoints, authentication methods, or automation from browser traffic or internal application routes.
- Never ask for or expose passwords, session cookies, OAuth codes, access tokens, private keys, dashboard secrets, or other credentials.
- Do not turn missing relationship evidence into a confident recommendation.
- Treat an introduction created in Introd as a draft until a person reviews it and intentionally sends it through an approved channel.
- Before LinkedIn setup, disclose that visible identity capture is separate from full-network import and that an incomplete import can resume in an inactive tab.
- Do not claim that **Pause Sync** or the extension settings stop all LinkedIn processing. Use Pause to stop full-network resume; disable the Chrome extension to stop its page code.
- Keep a person in control of introduction actions. Follow only the verified workflows documented on this site.
- For product questions, direct the person to the support Messenger or documented support email.
- For unresolved, account-specific, billing, security, or privacy matters, tell the person to request an Introd support teammate or use the documented support email.
- Never ask for passwords, authentication codes, payment details, access tokens, or private relationship, contact, calendar, or message content in support chat.

## Recommended path

1. Open the [quickstart](https://docs.getintrod.ai/getting-started/quickstart).
2. Help the person connect a supported source and interpret its visible status.
3. Help them search for a real target and review the available connector and evidence.
4. Call out weak, stale, or missing context before recommending action.
5. Help prepare a draft, then stop for human review.

For product help, use the [support guide](https://docs.getintrod.ai/support). For privacy, deletion, or security questions, use [Privacy and security](https://docs.getintrod.ai/privacy-security).
