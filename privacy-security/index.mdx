## Controls at a glance

| Goal | Current control | Result |
| --- | --- | --- |
| Stop Google or Microsoft sync | Disconnect the provider in [Integrations](https://app.getintrod.ai/settings/integrations) | Introd clears the stored connection tokens and stops future sync; imported Introd records remain |
| Clear one Chrome installation | Use **Clear local extension data** in extension Settings | Browser-local auth, settings, caches, queued signals, and diagnostics are cleared; server data remains and default capture settings return after reinitialization |
| Start account-data deletion | Use the account deletion control in [Settings](https://app.getintrod.ai/settings) | The current app starts deletion of dashboard-owned records and signs you out |
| Request complete privacy assistance | Email [privacy@getintrod.ai](mailto:privacy@getintrod.ai) | Introd can confirm the applicable request, identity checks, and policy timeline |

These controls are separate. Clearing extension data does not disconnect a provider, delete an Introd account, or serve as a durable capture opt-out. Disable Introd in Chrome when its page code must stop.
