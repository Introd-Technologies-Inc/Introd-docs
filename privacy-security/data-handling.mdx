Introd uses authorized account, network, and relationship data to help you review warm paths and prepare introduction drafts.

> Last verified against current product and extension source on August 11, 2026.

## Data categories

| Category | Examples in the current product | Customer-facing purpose |
| --- | --- | --- |
| Account and session data | Name, email address, authentication method, and session state | Create an account and maintain a signed-in Introd session |
| LinkedIn relationship data | Visible identity and relationship fields from permitted LinkedIn pages, connection-import records, sync counts, and path context | Build searchable network coverage and display path context |
| Google Workspace metadata | Gmail header metadata, Calendar event metadata, and Contacts data | Add authorized relationship evidence |
| Microsoft 365 metadata | Basic Outlook message metadata and Calendar metadata | Add authorized relationship evidence |
| Introduction workflow data | Targets, connectors, subjects, draft messages, and workflow status | Save and organize introduction drafts |
| Extension-local data | Extension auth state, settings, sync checkpoints, cached data, and diagnostics | Operate the installed extension and show sync status |

The current Google and Microsoft metadata syncs do not import email bodies, meeting contents, or private notes.

## Where controls apply

### Introd account

[Account Settings](https://app.getintrod.ai/settings) contains the current account deletion control. Starting that action signs you out and begins deletion of dashboard-owned product records. For a complete privacy request or confirmation, email [privacy@getintrod.ai](mailto:privacy@getintrod.ai).

### Provider connections

[Integrations](https://app.getintrod.ai/settings/integrations) controls Google Workspace and Microsoft 365 connections. Disconnecting either provider clears Introd's stored connection tokens and stops future sync jobs. Previously imported Introd records remain.

Provider-side consent is managed separately in the provider account.

### Chrome extension

**Pause Sync** stops the full-network connection import and automatic background resume. It does not stop contextual identity capture on other LinkedIn pages.

Turning off either capture setting makes the current background handler skip new profile-view signals and enrichment, but it does not stop current-page diagnostics, full-network recovery, upload of already-queued signals while authenticated, or LinkedIn host access. Disabling Introd in `chrome://extensions` stops its code from running. **Clear local extension data** removes auth state, caches, signals, and diagnostics from that Chrome installation, but defaults can turn capture back on after reinitialization. It does not remove server-side relationship records, disconnect Google or Microsoft, or delete the Introd account.

## Draft data boundary

**Save draft** stores the introduction workflow record in Introd. It does not send email, send a LinkedIn message, schedule delivery, or contact the target.

Review a draft before sharing it outside Introd. Remove confidential information and any context the connector is not permitted to forward.

## If data looks wrong

1. Pause the full-network LinkedIn sync. Disable the extension in Chrome too if you need contextual page processing to stop.
2. Record the affected person, provider, and approximate sync time without copying credentials.
3. Email [help@getintrod.ai](mailto:help@getintrod.ai).
4. For access, deletion, or other privacy rights, email [privacy@getintrod.ai](mailto:privacy@getintrod.ai).

See [Integration Data Usage](/privacy-security/integration-data-usage) for provider-specific boundaries and [Deletion and Privacy Requests](/privacy-security/gdpr-and-deletion) for removal options.
