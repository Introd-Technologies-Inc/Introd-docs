## Verified customer journey

| Step | Open | Expected result |
| --- | --- | --- |
| Create an account | [Sign up](https://app.getintrod.ai/sign-up) | A signed-in session opens Network Setup |
| Connect a source | [Network Setup](https://app.getintrod.ai/setup-network) | The source reports Connected, Partial, or a specific error |
| Verify integrations | [Integrations](https://app.getintrod.ai/settings/integrations) | Connection, sync, and evidence status are visible |
| Find a target | [People Search](https://app.getintrod.ai/search/people) | Synced people appear, or Introd reports that no matching data is available |
| Inspect paths | Select a person, then choose **View Paths** | Introd displays available connector evidence or an empty state |
| Prepare the ask | Choose **Request intro**, then **Save draft** | Introd reports **Intro draft saved** |
| Review drafts | [Introductions](https://app.getintrod.ai/introductions) | The saved record appears in the introduction workflow |

## Current boundaries

- The Chrome extension is available only through an Introd-provided testing build; these docs do not offer a public installation link.
- LinkedIn coverage depends on the identities LinkedIn renders in the signed-in browser session. A partial sync is a valid state.
- Google Workspace and Microsoft 365 contribute relationship metadata through explicit OAuth consent.
- A warm path is available only when the synced graph contains usable evidence. Introd does not guarantee a path for every target.
- **Save draft** stores a draft. It does not email, message, or otherwise contact a connector or target.
