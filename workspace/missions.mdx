Missions turn a relationship goal into a trackable draft. The app labels this area **Warm Paths** in the sidebar and **Missions** on the page.

[Open Missions](https://app.getintrod.ai/missions)

## Create a mission

1. Select **New Mission**.
2. Enter the outcome in **Goal**.
3. Optionally add a company, segment, or community.
4. Optionally choose a starting connector from your synced contacts. Leave it blank to record the goal without inventing a connector.
5. Add an optional title and context.
6. Select **Create mission**.

<Warning>
Creating a mission saves a draft only. It does not send an introduction request, email a connector, or contact a target.
</Warning>

## Start from a template

**Mission Templates** can prefill goals for fundraising, executive hiring, strategic partnerships, or customer development. Review every field before creating the mission; a template is a starting structure, not a recommended target or connector.

## Read the mission list

Each row is built from a real introduction or mission-draft record. It can show:

- the goal and optional focus area
- progress derived from the record status
- a warm-path score when evidence exists
- a selected or matched connector
- a next step that links back to the introduction workflow

| Display state | Underlying record state |
| --- | --- |
| Active | Draft, pending, or in progress |
| Completed | Completed |
| Paused | Declined or cancelled |

Progress, scores, and stored statuses summarize current records. They do not independently prove that an external action happened.

## Continue safely

Open the related introduction, verify the target and connector, and edit the draft before any external communication. If evidence is missing, sync more network data instead of assuming a path exists.
