Collections organize saved people around a goal without contacting anyone.

[Open Collections](https://app.getintrod.ai/collections)

## Create a collection

1. Select **Create new collection**.
2. Enter a name. A description is optional.
3. Choose **Private**, **Team**, or **Shared** from the visibility menu.
4. Select **Create collection**.

Visibility is stored with the collection. Confirm your workspace access model before using **Team** or **Shared** for sensitive lists.

## Add a person

1. Open **People** in the Introd sidebar.
2. Search for and select a saved contact.
3. In the person panel, select **Add to collection**.
4. Choose a collection and confirm.

If a result is only a public signal and is not yet a saved contact, Introd asks you to save it before adding it to a collection.

## Review and maintain collections

Use search, the collection tabs, and the sort menu to find a collection. Open one to review its saved people, then remove a person when they no longer belong in that workflow.

The collection overview can also show counts tied to its saved people, including companies, warm paths, introductions, and meetings. A zero means no matching workspace record is available.

<Note>
The quick-start labels on the Collections page are examples. Create the collection explicitly with **Create new collection**.
</Note>
