The **Sync Accounts** list shows the supported connection flows and the most recent status available to Introd.

[Open Sync Accounts](https://app.getintrod.ai/setup-network)

## Connect a source

### LinkedIn

LinkedIn sync is backed by the Introd browser extension.

1. Install the extension from the Chrome Web Store, or use the install action in Network Setup, and link it to your account. See [Install the extension](/chrome-extension/installation).
2. Open the extension popup and choose **Sync now** (or **Start sync**).
3. Read the consent prompt and choose **Allow direct-connection sync** only if you accept it.
4. Return to Network Setup and wait for the contact count or last-synced value to update.

The popup has no pause button, and closing it does not stop a sync. See [Sync and consent](/chrome-extension/linkedin-integration) for what stops it.

### Google

The Google Contacts, Calendar, and Gmail rows use a shared Google authorization flow. After you approve access, each row reports whether that specific Google service is connected.

Select **Connect** on any Google row, complete authorization, then return to Network Setup. A partial result means at least one requested Google sync needs attention.

### Outlook

Outlook authorization covers supported email and calendar metadata. Complete the Microsoft authorization and return to Network Setup to see whether both parts connected.

## Read the status

| Status | What it means | What to do |
| --- | --- | --- |
| Connected | Introd has a usable connection or imported LinkedIn records. | Check the detail line and last sync. Use **Manage** to run another sync when needed. |
| Partial | The account connected, but one or more supported parts need attention. | Select **Update** and complete authorization again. |
| Not connected | Introd has no usable current connection for that row. | Select **Connect** if you want to use the source. |

The detail line can also report a sync still in progress or historical evidence that requires reconnection. Do not use an old evidence count as proof that the current provider connection is healthy.

## Verify the result

1. Check the imported contact count and last-synced time.
2. Open [People](https://app.getintrod.ai/search/people) and confirm expected records are present.
3. If the row remains partial or pending, retry authorization before importing the same contacts another way.

Connecting or syncing an account imports relationship evidence. It does not email contacts or send introduction requests.
