Network Setup is the control center for bringing relationship data into Introd.

[Open Network Setup](https://app.getintrod.ai/setup-network)

## Recommended setup path

1. Connect LinkedIn and complete an extension-backed sync.
2. Connect Google or Outlook if you want email and calendar relationship evidence.
3. Import a CSV only when you have contacts not covered by a connected source.
4. Open **All My Contacts** or **People** and verify that real records appear.
5. Review connection status and the last-updated time before relying on paths.

For the introduction composer readiness check, Introd expects LinkedIn plus Gmail or Outlook to be connected.

## Setup sections

| Section | Current purpose |
| --- | --- |
| Sync Accounts | Connect LinkedIn, Google, and Outlook; review provider status and sync details. |
| Import Contacts | Preview and import a CSV, or start Google or Outlook authorization. |
| Invite Team | View the current account. Team collaboration controls are not configured yet. |
| Alumni Networks | Save alumni or VC community selections to your Introd profile. |
| Groups | Save catalog group selections to your Introd profile. |
| All My Contacts | Review the people currently available in your workspace. |

<Note>
The setup progress indicator is an orientation aid. Confirm the provider status, contact count, and actual People results before treating setup as complete.
</Note>
