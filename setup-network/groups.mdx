Groups currently stores group labels as profile selections. It is not a discussion, invitation, or external-community system.

[Open Groups](https://app.getintrod.ai/setup-network/groups)

## Save a catalog group

1. Find a group under **Suggested groups**.
2. Select **Join**.
3. Confirm that it appears under **My Groups**.

Use the trash action to remove a saved catalog group. Search filters the catalog groups already shown in **My Groups**.

## Custom group names

**Create a group** records the name as a profile selection. The current My Groups table displays catalog groups only, so a custom name may not appear there after it is saved.

<Warning>
Joining or creating a group does not create a shared workspace, verify membership, invite people, load discussions, or send messages. Member, activity, discussion, and engagement summaries on this screen are not live collaboration records.
</Warning>

Controls such as **Browse all groups**, **View**, invitations, and discussion filters do not currently open a working group workspace.
