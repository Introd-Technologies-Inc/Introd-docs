Import Contacts supports a local CSV preview and provider authorization for Google or Outlook.

[Open Import Contacts](https://app.getintrod.ai/setup-network/import)

## Import a CSV

1. Choose **CSV File**.
2. Drop a CSV onto the upload area or select **Choose file**.
3. Review the preview and the number of contacts found.
4. Select **Import contacts** only when the rows look correct.

Introd recognizes common headings for:

- full name, or separate first and last name
- email
- company, organization, or account
- title, job title, or role

A parsed row needs at least a name or an email. The page previews the first five rows and imports all parsed rows when you confirm.

<Warning>
The current importer does not show a duplicate-resolution step. Remove duplicate or unwanted rows from the CSV before importing.
</Warning>

## Google and Outlook

Choosing **Gmail** starts Google authorization. Choosing **Outlook** starts Microsoft authorization. These options connect the provider; they do not show the CSV preview.

Choosing **Other Email** records an access request only. It does not import Yahoo, iCloud, AOL, or another mailbox today.

## After import

Open **People** and search for several known records. A successful import adds contact records to Introd; it does not send them a message.
