Import Contacts brings in people from a file. Provider connections for Google Workspace and Microsoft 365 are made from [Sync Accounts](/setup-network/sync-accounts).

[Open Network Setup](https://app.getintrod.ai/setup-network?source=csv)

> Last reviewed against current product source on October 30, 2026.

## Import a contacts CSV

1. Choose **CSV**.
2. Drop a `.csv` file onto the upload area or choose a file. The limit is 10 MB. Export Excel files as CSV first.
3. Review the preview and the number of contacts found. **Show first 5** shows the first rows.
4. Choose **Import contacts** only when the rows look correct.

Download `introd-contact-template.csv` if you want a template. Introd recognizes common headings for full name or separate first and last name, email, company, and title or role. A row needs at least a name or an email.

<Warning>
The importer does not show a duplicate-resolution step. Remove duplicate or unwanted rows from the CSV before importing.
</Warning>

## Apple Contacts

There is no direct Apple Contacts connection. Export your contacts as a file, then import that file as a CSV.

## Import your LinkedIn `Connections.csv`

1. Open **Import LinkedIn connections** from Collections or Network Setup.
2. Upload the `Connections.csv` file from your LinkedIn data export. The limit is 7 MB.
3. Select the workspace and tick the consent checkbox.
4. Review the server preview, then import.

Introd says it never asks for your LinkedIn password. The import shows **Queued securely**, **Importing connections**, and then **Import complete**, **Import completed with warnings**, or **Import needs attention**.

## After import

Open **People** and search for several known records. A successful import adds contact records to Introd; it does not send them a message.
